# Webhook & Callback URLs Configuration

Configure these webhook / notification URLs in your payment gateway and service provider portals:

### 1. Paystack Webhook
- **URL:** `https://yourdomain.com/webhook/paystack`
- **Method:** `POST`
- **Where to set:** Paystack Dashboard -> Settings -> API Keys & Webhooks -> Webhook URL

### 2. Flutterwave Webhook
- **URL:** `https://yourdomain.com/webhook/flutterwave`
- **Method:** `POST`
- **Where to set:** Flutterwave Dashboard -> Settings -> Webhooks -> Secret Hash & Webhook URL

### 3. Monnify Webhook
- **URL:** `https://yourdomain.com/webhook/monnify`
- **Method:** `POST`
- **Where to set:** Monnify Dashboard -> Developer Options -> Webhook URL

### 4. VTpass Notification / Webhook URL
- **URL:** `https://yourdomain.com/webhook/vtpass`
- **Method:** `POST`
- **Where to set:** VTpass Partner Dashboard -> Account Settings -> Notification / Callback URL
